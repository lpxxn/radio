# 手机现代播放页与会话恢复

此次完全替换手机复古机身布局，桌面继续使用原有面板。手机使用浅色背景、声波矢量封面、圆形播放主按钮、独立辅助操作及底部选台面板。无模拟频率刻度和音量滑块，使用系统音量键。菜单保留配色与关于，电源键停止播放后退出。

手机原先的系统手写字体仍会覆盖通用 sans-serif，因此新增随包提供的 Noto Sans SC Regular/Bold，不修改系统字体。许可保存在 assets/fonts/OFL.txt。

## 真实手机验证

设备 PLJ110，屏幕 1080×2374，通过 USB 安装更新，保留原目录和收藏。仅在应用处于解锁前台时读取 UI/截图。

1. 从“我的收藏”选择“北京新闻广播”。应用保存 favorites=true、我的收藏、11 个有序队列 ID。
2. 点击退出并强制停止本应用，随后 am start 返回 COLD 冷启动。
3. 启动页面仍显示北京新闻广播、已暂停、我的收藏 11 台；无自动播放。
4. 点击下一台，保存电台变为“北京音乐广播”，仍为我的收藏 11 台。
5. 安装最终字体版本并再次冷启动，恢复北京音乐广播及收藏 11 台。真机截图确认新字体生效、标题完整、顶部留白和底部列表均可见，手机无音量控件。

最终主页截图：[android-modern.png](previews/android-modern.png)。顶部标题栏固定在安全区内，封面和播放内容在其下独立滚动，避免大字设置时标题被滚动裁切。配色跟随本机已保存的选择；截图为松间绿。

底部选台/收藏面板截图：[android-modern-picker.png](previews/android-modern-picker.png)。原有收藏与顺序保留，可使用右侧手柄拖动排序。

应用图标与启动页已替换模板 Flutter 标志。真机覆盖安装后捕获冷启动画面，显示珊瑚橙收音机图标与暖白背景：[android-startup.png](previews/android-startup.png)。此更新未清空目录、收藏和播放会话。

这轮验证了真实持久化和冷启动恢复，不把模拟引擎测试当作手机测试。此前用户确认过实际播放及断网恢复声音，此轮主要验证页面和会话。
