# 手机页面字体

Noto Sans SC Regular / Bold，来自 [Noto CJK 官方仓库](https://github.com/notofonts/noto-cjk/tree/main/Sans/SubsetOTF/SC)，使用 SIL Open Font License 1.1。完整许可见同目录 OFL.txt；许可也作为应用资源打包。字体原文件未修改。

下载于 2026-11-10：

- https://raw.githubusercontent.com/notofonts/noto-cjk/main/Sans/SubsetOTF/SC/NotoSansSC-Regular.otf
- https://raw.githubusercontent.com/notofonts/noto-cjk/main/Sans/SubsetOTF/SC/NotoSansSC-Bold.otf
- https://raw.githubusercontent.com/notofonts/noto-cjk/main/Sans/LICENSE

pubspec.yaml 注册为 RadioSans，只有手机主题指定此字体，避免手机厂商的系统手写字体影响 UI。字体随安装包提供，首次打开和断网时无需下载。
